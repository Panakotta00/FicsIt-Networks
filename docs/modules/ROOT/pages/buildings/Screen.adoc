= Large Screen
:description: The large screen allows you to place a screen with any size and orientation into the world.

The large screen allows you to place a screen with dynamic height and width
onto a foundations or walls.

You can also rotate it in any direction if you want even more customizability.

You can connect the screen to a computer network and then reference
the screen in the gpu's bind function to allow writing to it.

The maximum size of a screen is 10 x 10.
