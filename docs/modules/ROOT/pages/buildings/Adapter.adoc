= Adapter
:description: The Adapter allows to connect existing buildings from CSS and other mods to the computer network.

[cols="1,3"]
|===
|Building Type
|network component

|Max Network Connections
|1
|===

[cols="a"]
|===
|Ingame

|image::buildings/Adapter_ig.jpg[300,300,role="left"]
|===

The adapter is a special type of building you can not directly place as buildable, but is placed on existing buildings when you use the network cable.
If you try to connect a cable to an existing building that doesn't have a connector on it but is registered with FicsIt Networks or has a power connector.
You can see the adapter only if the building has no power connector, in every case else the adapter will be visible somewhere.

If you want to get rid of an adapter, you will need to destruct the whole building.
